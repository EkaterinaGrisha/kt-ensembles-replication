# Материалы к статье об объединении предсказаний моделей отслеживания знаний

Здесь лежат расчёты, из которых собрана статья: сценарии счёта, их результаты,
сборщик таблиц и генератор рисунков. Каждое число статьи печатается отсюда, и
любое из них можно получить заново, не заглядывая в текст.

## Что можно запустить прямо здесь

    python -m scripts.make_c5_tables            # все тринадцать таблиц статьи
    python -m scripts.make_c5_figures_html      # три рисунка, SVG + PNG + PDF
    python -m pytest tests -q                   # модульные тесты модулей ktx/

Всё это работает без каких-либо внешних данных и без файлов предсказаний.
Сборщик печатает все тринадцать таблиц в том виде, в каком они стоят в статье,
поэтому сличить напечатанное с опубликованным можно построчно.

Генератор рисунков считает точки диаграмм надёжности из файлов предсказаний, а
без них берёт готовый `artifacts/ensembles/reliability_points.csv`, поэтому все
три рисунка собираются и здесь.

## Чего здесь нет

Файлов предсказаний обученных моделей — их полтора гигабайта. Без них не
запускаются сценарии счёта (`run_*.py`, `cluster_bootstrap_*.py`,
`component_models.py`, `classical_concepts.py`, `family_alignment.py`): они
читают предсказания и пишут таблицы. Сами таблицы здесь готовые, так что
проверить можно всё, кроме их перевычисления. Сценарии перенесены ради
проверяемости: по ним видно, как именно получено каждое число.

## Раскладка

    ktx/         модули: ансамбли, метрики, статистика, кластерный бутстрап
    scripts/     сценарии счёта, сборщик таблиц, генератор рисунков
    tests/       модульные тесты перенесённых модулей
    artifacts/   результаты расчётов
    paper/       рисунки статьи в трёх форматах (текста статьи здесь нет)
    configs/     конфигурация предобработки: числа компонентов и заданий

## Зависимости

    numpy, pandas, scipy, scikit-learn, joblib

Этого хватает сборщику таблиц, генератору рисунков и почти всем модульным
тестам. Дополнительно:

    pip install -e ".[test]"         # pytest
    pip install -e ".[compute]"      # torch и xgboost, только для сценариев счёта
    pip install -e ".[calibration]"  # netcal

netcal вынесен из основного списка намеренно: он тянет torch и matplotlib, а
ошибка калибровки во всех результатах статьи посчитана функцией `ece_equal_mass`
на чистом numpy. Проверки, которым netcal или xgboost всё же нужны, без них
пропускаются, а не падают.
