# Материалы к статье об объединении предсказаний моделей отслеживания знаний

Здесь лежат расчёты, из которых собрана статья: сценарии счёта, их результаты,
сборщик таблиц, генератор рисунков и сверщик, проверяющий каждое число рукописи
против результатов.

## Что можно запустить прямо здесь

    python -m scripts.make_c5_tables            # все девять таблиц статьи
    python -m scripts.make_c5_figures_html      # три рисунка, SVG + PNG + PDF
    python -m scripts.check_c5_numbers          # проверка чисел рукописи
    python -m scripts.c5_units --check paper/c5_ensembles_ru.md

Сверщик читает рукопись из `paper/` и таблицы из `artifacts/ensembles/`, поэтому
работает без каких-либо внешних данных. Он и есть главная проверка: если число в
тексте разойдётся с расчётом, сверщик покраснеет.

## Чего здесь нет

Файлов предсказаний обученных моделей — их полтора гигабайта. Без них не
запускаются сценарии счёта (`run_*.py`, `cluster_bootstrap_*.py`,
`component_models.py`, `classical_concepts.py`, `family_alignment.py`): они
читают предсказания и пишут таблицы. Сами таблицы здесь готовые, так что
проверить можно всё, кроме их перевычисления. Сценарии перенесены ради
проверяемости: по ним видно, как именно получено каждое число.

## Раскладка

    ktx/         модули: ансамбли, метрики, статистика, кластерный бутстрап
    scripts/     сценарии счёта, сборщик таблиц, генератор рисунков, сверщик
    artifacts/   результаты расчётов
    paper/       выверенный исходник рукописи и рисунки
    configs/     конфигурация предобработки: числа компонентов и заданий

## Зависимости

    numpy, pandas, scipy, scikit-learn, netcal, torch

Торч нужен только двум сценариям — вниманию и разреженной смеси. Сборщик таблиц,
генератор рисунков и сверщик обходятся первыми четырьмя.
